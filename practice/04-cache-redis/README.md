# 04 Cache and Redis

## Цель
Добавить кэширование и понять стратегию инвалидации.

## Практика
- Подключи Redis к API.
- Закэшируй чтение списка ресурсов с TTL.
- Реализуй инвалидацию кэша после изменения данных.
- Сравни latency до и после кэширования.

## Результат
- Реализованный cache-aside сценарий.
- Небольшой отчет с измерениями.
