# 09 Testing

## Цель
Покрыть критичный функционал тестами и собрать минимально надежный regression suite.

## Практика
- Напиши unit-тесты для сервисов.
- Напиши интеграционные тесты для API + БД.
- Добавь негативные кейсы: валидация, 404, 409, 500.
- Настрой отчет по покрытию.

## Результат
- Папка `tests/` с разделением unit/integration.
- Отчет по coverage.
