# 06 Auth and Security

## Цель
Реализовать безопасовую основу: регистрация, логин, защита endpoint.

## Практика
- Сделай регистрацию и логин.
- Хешируй пароли через bcrypt или argon2.
- Добавь access token и refresh token.
- Добавь роль `admin` и ограничение доступа к одному endpoint.

## Результат
- Набор auth endpoint.
- Мини-чеклист безопасности по OWASP Top 10.
