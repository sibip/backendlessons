# 11 Observability

## Цель
Сделать поведение приложения наблюдаемым: логи, метрики, диагностика ошибок.

## Практика
- Перейди на структурированные JSON-логи.
- Добавь `request_id` и проброс по цепочке вызовов.
- Зафиксируй метрики: latency, error rate, throughput.
- Разбери 2 инцидента по логам.

## Результат
- Базовый observability набор.
- Короткий postmortem по двум ошибкам.
