# 08 Docker and Deploy

## Цель
Упаковать backend и зависимости в контейнеры и поднять рабочий стенд.

## Практика
- Создай `Dockerfile` для приложения.
- Создай `docker-compose.yml` для API + DB + Redis.
- Добавь healthcheck и переменные окружения.
- Проверь запуск командой `docker compose up`.

## Результат
- Повторяемый локальный запуск в контейнерах.
- Инструкция запуска в `README.md` проекта.
