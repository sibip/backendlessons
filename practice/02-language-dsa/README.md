# 02 Language and DSA

## Цель
Закрыть минимальный алгоритмический базис и уверенную работу с базовыми структурами данных.

## Практика
- Реши 10 задач: массивы, строки, словари/хеш-таблицы, сортировки.
- Для каждой задачи зафиксируй сложность по времени и памяти.
- Напиши unit-тесты на edge-case сценарии.

## Результат
- Папка `solutions/` с решениями.
- Папка `tests/` с тестами.
