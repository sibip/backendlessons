# 03 PostgreSQL and SQL

## Цель
Научиться проектировать схему, писать рабочий SQL и понимать влияние индексов.

## Практика
- Спроектируй таблицы `users`, `products`, `orders`, `order_items`.
- Напиши DDL и миграции.
- Реализуй 8-10 SQL запросов с `JOIN`, `GROUP BY`, `HAVING`.
- Проверь планы выполнения для 2-3 запросов (`EXPLAIN ANALYZE`).

## Результат
- SQL-скрипты `schema.sql`, `seed.sql`, `queries.sql`.
- Краткие заметки по индексам и узким местам.
