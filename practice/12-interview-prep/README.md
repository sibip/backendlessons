# 12 Interview Preparation

## Цель
Подготовить уверенную подачу опыта и ответов на типовые backend-вопросы.

## Практика
- Проведи 3 мок-собеседования по 45-60 минут.
- Запиши ответы на 30 вопросов по API, БД, безопасности, тестам, деплою.
- Подготовь 2-3 истории по шаблону STAR.
- Отрепетируй 3-минутный рассказ о проекте.

## Результат
- Файл `answers.md` с краткими, структурированными ответами.
- Шпаргалка по проектным кейсам.
