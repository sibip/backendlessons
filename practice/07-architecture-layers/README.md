# 07 Architecture Layers

## Цель
Структурировать backend-проект по слоям и убрать смешение ответственности.

## Практика
- Раздели код на `controller`, `service`, `repository`.
- Вынеси конфиг в `.env` и config-модуль.
- Добавь глобальную обработку ошибок.
- Добавь логирование входящих запросов.

## Результат
- Чистая структура проекта.
- Документ с описанием слоев и их обязанностей.
