# Review: 03 Language and DSA

Контрольные вопросы, по которым я буду оценивать твой код.

---

## Структура решений

- [ ] Минимум 10 задач: есть представители всех категорий — массивы, строки, хеш-таблицы, сортировки?
- [ ] Каждое решение в отдельном файле с описательным именем (`two-sum.js`, `reverse-string.js`)?
- [ ] В начале каждого файла есть комментарий: постановка задачи + сложность O(n) / O(1) по времени и памяти?
- [ ] Единица решения — чистая функция с явными входом и выходом (не `console.log` вместо `return`)?

## Корректность алгоритмов

- [ ] Two Sum / аналог решён через хеш-таблицу (O(n)), а не двойным циклом (O(n²))?
- [ ] Задачи на строки не используют конкатенацию в цикле (`str += ...`) — используется `join()`?
- [ ] Сортировка реализована вручную (хотя бы одна) или встроенная используется с объяснением компаратора?
- [ ] Нет решений через `eval`, `Function`, или магические регулярки без объяснения?

## Сложность

- [ ] Для каждого решения зафиксирована Time Complexity (лучший/средний/худший случай)?
- [ ] Для каждого решения зафиксирована Space Complexity?
- [ ] Нет ложных утверждений — например, O(n log n) не подписано как O(n)?
- [ ] Там где есть два решения (brute force + оптимальное), оба задокументированы?

## Тесты

- [ ] Тесты написаны через Jest или Node assert — не просто `if (result !== expected) console.log("fail")`?
- [ ] Каждая задача имеет хотя бы 3 теста: базовый случай, граничный случай, пустой/нулевой вход?
- [ ] Edge cases покрыты: пустой массив `[]`, массив из одного элемента `[x]`, отрицательные числа, пустая строка?
- [ ] Тесты изолированы — не зависят от порядка выполнения?
- [ ] Все тесты проходят (`npm test` без ошибок)?

## Понимание структур данных

- [ ] Можно объяснить, почему для поиска используется `Map`/`Set` (O(1)) вместо `Array.includes` (O(n))?
- [ ] Стек и очередь реализованы или продемонстрированы их отличия?
- [ ] Хотя бы одна задача на скользящее окно (sliding window) или два указателя (two pointers)?

## Качество кода

- [ ] Переменные названы осмысленно (`left`, `right`, `seen` — не `a`, `b`, `x`)?
- [ ] Нет магических чисел без объяснения?
- [ ] Решения не скопированы с LeetCode дословно — есть хотя бы переименование и комментарий своими словами?
